# VITRINE

Plataforma privada de talentos do futebol — Etapa 1: identidade provisória, Home e mockups.

```bash
npm install
npm run dev      # http://localhost:3000 → redireciona para /pt
npm run build && npm start
```

Rotas: `/pt` · `/es` · `/pt/cadastro` · `/pt/atleta/exemplo` · `/pt/profissional`

Arquitetura, papéis, privacidade e próximos passos: [`docs/ARQUITETURA.md`](docs/ARQUITETURA.md).
